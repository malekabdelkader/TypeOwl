# Contributing to TypeOwl

Thanks for your interest in contributing! 🦉

## Getting Started

1. Fork the repo
2. Clone your fork
3. Install dependencies: `npm install`
4. Build: `npm run build`
5. Make your changes

## Development

```bash
# Build the library
npm run build

# Watch mode
npm run dev

# Test with examples
cd examples/backend && npm install && npm run dev
cd examples/frontend && npm install && npm run dev
```

## Submitting Changes

1. Create a branch for your changes
2. Make your changes
3. Test that everything builds
4. Open a PR with a clear description of what you changed

That's it! We'll review and work with you to get it merged.

## Questions?

Open an issue or start a discussion. We're happy to help!
