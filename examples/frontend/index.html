Why TypeOwl?

Type safety without the complexity

🔄

Incremental Sync

Only downloads type files that changed. Hash-based comparison means instant syncs when nothing changed.

📦

No Monorepo Required

Backend and frontend in separate repos? Different teams? TypeOwl bridges them over HTTP.

✅

Optional Zod Validation

Use typeowl.endpoint() with Zod for runtime validation, or extract types directly from .ts files.

🗺️

Endpoint Type Map

Auto-generated ApiEndpoints interface maps every route to its request/response types.

💾

Offline Cache

Types are cached locally. When your backend is down, development continues with cached types.

👀

Watch Mode

Poll for changes during development. Types update automatically when your backend changes.

How It Works

Simple architecture, powerful results

Backend (deployed)
/api/users ← Your actual API
/__typeowl ← Lightweight manifest (JSON)
/__typeowl/types/*.d.ts ← TypeScript definitions
HTTP (dev-time)
↓
Frontend (npm run dev)
1. typeowl sync ← Fetches manifest, compares hashes
2. Downloads changed type files only (incremental!)
3. import type { User } from '@typeowl' ← Full autocomplete!
